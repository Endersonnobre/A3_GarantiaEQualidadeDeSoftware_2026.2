# Sistema de Finanças Pessoais

Projeto acadêmico em Java 17 para planejamento e implementação de testes com base na especificação fornecida separadamente.

## Execução

```bash
mvn test
mvn package
java -cp target/classes br.edu.financas.app.FinancasApplication
```

O sistema usa repositórios em memória e não exige banco de dados. Os estudantes devem considerar a especificação como oráculo e desenvolver sua própria suíte de testes. O código entregue não documenta divergências conhecidas.
